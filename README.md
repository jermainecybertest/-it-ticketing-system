# 🖥️ Helpdesk Ticketing System Simulation Lab  

This project simulates real-world helpdesk operations in an enterprise IT environment. It demonstrates the full ticket lifecycle process, including ticket creation, resolution documentation, and escalation procedures. The lab highlights core service desk responsibilities such as issue categorization, prioritization, end-user communication, and cross-team collaboration.

---

## 🎯 Project Objectives

- Practice professional ticket documentation standards  
- Simulate structured troubleshooting workflows  
- Demonstrate understanding of escalation protocols  
- Develop communication and incident management skills used in enterprise IT support environments  

---

## 📝 Activity 1: Simulated Ticket Creation **(SS Required)**

**Objective:** Understand how service desk tickets are logged, categorized, and prioritized.

### 🔧 Tasks Performed

- Created a simulated helpdesk incident ticket using standard ITSM fields  
- Documented a clear and concise issue summary describing end-user impact  
- Categorized the incident under the appropriate support domain (Hardware / Software / Network)  
- Assigned a priority level based on business impact and urgency

## 🚨 Activity 3: Ticket Escalation Procedure **(SS Required)**

**Objective:** Understand when and how to escalate incidents beyond Tier 1 support.

### 🖥️ Scenario

A user was unable to access the company’s financial database. Initial troubleshooting steps included credential reset and basic network connectivity checks; however, the issue persisted after standard Tier 1 support procedures.

### 🔧 Escalation Actions Taken

- Identified the issue as outside Tier 1 support scope after completing baseline troubleshooting  
- Escalated the incident to the **Database Administration Team**  
- Included detailed troubleshooting notes, error messages, and user impact description  
- Flagged the ticket with elevated priority due to business-critical system involvement
